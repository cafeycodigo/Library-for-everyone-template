# Library for Everyone

A web-based library management system built with HTML, CSS, Bootstrap 5, and vanilla JavaScript. Manage users, books, and loans through an intuitive admin dashboard.

## Features

- **Public Pages**: Landing page, About Us, Terms & Conditions, Privacy Policy
- **User Registration & Login**: Account creation with form validation
- **Admin Dashboard**: Real-time statistics from JSON data
- **User Management**: Full CRUD operations with search and filters
- **Book Management**: Full CRUD operations with search, genre and status filters
- **Responsive Design**: Works on desktop, tablet, and mobile

## Project Structure

```
├── index.html              # Landing page
├── login.html              # Login page
├── registro.html           # Registration page
├── nosotros.html           # About Us page
├── terminos.html           # Terms & Conditions page
├── privacidad.html         # Privacy Policy page
├── data.json               # Initial data (users, books, loans)
├── css/
│   └── style.css           # Global styles
└── admin/
    ├── index.html          # Admin dashboard
    ├── usuarios.html       # User CRUD
    └── libros.html         # Book CRUD
```

## Getting Started

1. Clone or download the project
2. Open `index.html` in a browser using a local server (e.g., VS Code Live Server)
3. Use the login credentials to access the admin panel
